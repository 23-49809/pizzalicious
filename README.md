# Pizzalicious – Pizza Website

Pizzalicious is a fully responsive, front-end pizza-themed website built using HTML, CSS, and JavaScript. It includes multiple sections such as Home, About, Services, Menu, Blog, Cart, and Contact. The site features a custom design, interactive UI components, and a functional JavaScript-based cart system.

The project showcases modern layout techniques, transitions, custom animations, and a structured menu system with add-to-cart functionality.  
Core layout structure and content are defined in **index.html** :contentReference[oaicite:0]{index=0}, while visual styling and responsive behavior are handled in **style.css** :contentReference[oaicite:1]{index=1}.

---

## Features

### Home Section
- Hero introduction with animated pizza icon  
- Navigation with built-in search bar  
- Responsive layout with image and text pairing

### About Section
- Introduction to Pizzalicious with brand story  
- Highlighted features such as quality, freshness, and availability

### Services Section
- Three service cards showcasing delivery, online payment, and fresh food  
- Styled grid layout

### Menu System
- Nine menu items with images, icons, ratings, and pricing  
- “Add to Cart” buttons powered by JavaScript  
- Cart panel updates dynamically with items, prices, and total computation

### Blog Section
- Three structured blog entries with thumbnails, dates, authors, and descriptions

### Contact Section
- Contact form with fields for name, email, and address  
- Integrated map embed for location reference

### Cart System
- JavaScript-driven cart panel  
- Item listing, total calculation, and checkout action  
- Cart logic included in the script block inside **index.html** :contentReference[oaicite:2]{index=2}

## How to Run the Project

1. Clone or download the repository.
2. Ensure the folder structure remains intact (especially the **images** directory).
3. Open `index.html` in any modern browser.

No additional dependencies or build steps are required.
